一本书的两种活法：解谜 与 翻阅

同一条命令可以生成两类交互书：解谜书（每章两关）与历史图文书（每章若干跨页）。下面把主题配色、全部内页组件的用法、以及真实构建出来的案例放在一起——选主题 → 挑组件 → 照着案例写。

组件总览

10 种组件 / 22 种样式

每页 = 一个跨页。组件只声明「左页放什么、右页放什么」，布局、翻页、页码存档、手机端堆叠都由 PagedChapter 处理。数据里的坐标 x/y 都是原图上的百分比。

kindvariant左页 → 右页用在什么地方
A · 版式（一本书 / 一章的开头）
openerplate满幅插图（压章号）→ 章号、副题、大标题、导语、关键数字章扉页。给一章一个"翻开"的仪式感
openerplain巨大章号水印 + 徽章 → 同上没有大图时的文字扉页
tocplain配图或羽笔 → 编号纲要，点条目展开摘要本章有哪些内容 / 阅读路线
B · 叙述（正文与图文）
textplain配图、引文 → 正文单栏正文
textdropcap同上 → 正文首字下沉开篇叙述
textcolumns前半（下沉）+ 配图 → 后半长文跨页连续排版
featuresplit原比例插图 → 正文最朴素的图文对照
featurehotspot图上编号热点 → 正文；点编号换成该处注释城景、器物、画作的讲解
featurestack首段大字导语 → 上图下文先给一句气氛，再讲细节
C · 时间轴（大事件）
timelinerail年份 + 节点 + 标题/摘要的竖排列表 → 详情 + ‹ ›年代顺序；条目可带 short 做副标题
timelineseals带年份的蜡封分组，展开条目 → 详情王朝 / 阶段；翻到别组会自动展开
timelineribbon当前节点插图 → 横向年轴 + 年份大字 + 详情每个节点都有图（同一物的多次重建）
D · 探索（分类、对比、测验）
cardsgrid分类筛选 + 带色条的卡片 → 详情一组同类事物（职业、兵种、建筑）
cardsaccordion筛选 + 当前项配图 → 手风琴要逐项展开细读
cardsflip翻开计数 → 2 列翻面卡冷知识、传闻、迷信
comparetabs蜡封分期 + 图上编号点 → 当前分期详情同一地方的不同时期
comparecolumnsA 期 → B 期（并排）两方对比：两种船、两种制度
quizchoice题目 + 配图 → 选项（错因 / 解析）章末回顾
quizorder题目 → 按顺序点按，错了清空排年代、排工序
E · 图谱与地图
graphtree家谱（按 parent 自动分层）→ 人物详情 + 关系跳转血缘、世系
graphweb自由坐标关系网 → 详情 + 关系列表结盟、敌对、联姻
mappins图例筛选 + 地图点位 → 地点详情地点分布
mapjourney逐站连线 → 详情 + 第 n / N 站行军、航线、迁徙

新增：章扉页与纲要 写法

// 章扉页
{
  kind: 'opener', variant: 'plate',
  chapter: '第三章',
  latin: 'DE REGNO',
  title: '三王之间',
  image: 'illustrations/town.svg',
  lede: '一百四十年里，王冠换了四顶。',
  stats: [
    { n: '140 年', label: '内战' },
    { n: '3', label: '个王朝' },
    { n: '11', label: '场战役' },
  ],
  quote: { text: '王冠不属于戴它的人。', source: '—— 宫廷记录' },
}
// 本章纲要
{
  kind: 'toc',
  title: '本章条目',
  note: '按时间顺序排列，点击展开。',
  items: [
    { title: '盐与船', short: '城市的起点',
      text: '……', page: 12 },
    { title: '第一次远航', short: '1421',
      page: 15 },
  ],
}
// page 只是页码标注，不跳转；
// 点条目在下方展开摘要。
历史内容的两个新字段。任何 Entry 都能写 facts: [{ k: '地点', v: '灰港' }, …]，详情里会排成两列事实卡（地点 / 参战方 / 结果 / 影响）；source 在详情末尾显示史料出处。时间轴的 short 现在是条目的副标题，扫一眼就能看懂每个节点。

案例

《灰港编年史》实机截图

示例书是虚构的港城史，两章 20 个跨页，把上面除 opener / toc 外的 20 种样式都用了一遍。按类别看：

3.1 目录与外壳 壳

目录

双页目录

左页书名与三句题记，右页章节列表。历史书默认 unlock: open，全部章节可直接点开；解谜书是逐章解锁。

收尾

本章终

最后一页的按钮变成「读完本章」。有 meta.excerpt 的章节先播摘录过场，没有就直接收尾。

解谜章

同一本书里的解谜章

图文章与解谜章可以混排：App 看章节有没有 pages 决定用哪套外壳。

3.2 图文介绍 叙述

ch1 · 01

正文 · 首字下沉 text·dropcap

左页配图与引文，右页正文。glossary 的词变红，点开在右页顶部浮出释义。

ch1 · 02

图文 · 热点 feature·hotspot

点编号换注释。图按原比例显示，坐标就是原图上的百分比，不会错位。

ch2 · 01

正文 · 跨页 text·columns

长文连续排到右页，左页首段仍下沉。

ch2 · 02

图文 · 分栏 feature·split

左图右文，海图、长卷都完整显示。

ch2 · 03

图文 · 上图下文 feature·stack

首段提到左页做成大字引文，右页上图下文，避免左页空着。

ch2 · 12

尾声 text·plain

左页一句居中引文，右页短正文，用来收尾。

3.3 大事件时间轴 时间

ch1 · 03

竖排年表 timeline·rail

年份右对齐、节点连线贯穿，标题下多了一行摘要；选中项左侧出现色条。

ch2 · 04

蜡封分组 timeline·seals

按航次分组的蜡封，点开才展开条目；用 ‹ › 翻到别组时会自动展开。

ch2 · 05

横向年轴 timeline·ribbon

左页是当前节点的插图，右页年轴下方放大当前年份和标题。

3.4 地图与人物图谱 空间

ch1 · 07

地图 · 点位 map·pins

图例可筛选；地点名只在悬停或选中时出现，避免图上文字打架。

ch2 · 10

地图 · 路线 map·journey

按顺序连成虚线，只画走到当前的站；places 的顺序就是路线。

ch1 · 06

家谱 graph·tree

只写 parent，自动分层居中。节点现在是名牌（姓名 + 年份），比圆点更好认。

ch2 · 09

关系网 graph·web

结盟、敌对、联姻；dashed 表示冲突或间接关系，选中后相关连线会亮起。

3.5 探索与测验 互动

ch1 · 04

分类卡片 cards·grid

卡片左缘是分类色条，图标独立成行；选中抬升并在右页展开。

ch1 · 05

分期对比 compare·tabs

蜡封切换时期，图上还能叠编号点看细节。

ch2 · 06

手风琴 cards·accordion

逐项展开细读，左页跟着显示当前项配图。

ch2 · 07

翻面卡片 cards·flip

正面图标 + 标题，背面一句话；左页显示翻开进度。

ch2 · 08

并排对比 compare·columns

两方各占一页，不用来回切换。

ch1 · 08

小测 · 单选 quiz·choice

选错抖动并说明为什么错，选对给解析。

ch2 · 11

小测 · 排序 quiz·order

options 按正确顺序写，显示时打乱；点错清空重来。

复用

三条命令开始
S=interactive-book-builder
python3 $S/scripts/themes.py list
python3 $S/scripts/new_book.py 书名目录 \
  --type history --title 灰港编年史 \
  --layout heraldic --emblem crown \
  --cover wine --paper vellum --install

python3 $S/scripts/add_chapter.py 书目录 3 --kind paged
python3 $S/scripts/themes.py set 书目录 --cover umber --paper linen

记住四件事

  • 图文章只写数据，不写组件；从案例里复制同 kind·variant 的页面。
  • 颜色只用 ink / accent / paper / tint(k)，换纸张后仍然协调。
  • SVG 当底图要写 width/height，否则没有固有尺寸、显示不出来。
  • 历史内容多用 facts 和 source，详情页才有史料感。
