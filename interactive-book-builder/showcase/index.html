Interactive Book Builder · Showcase

一本书的两种活法：
解谜 与 翻阅

这个 skill 能生成两种交互书。左边是《百年孤独》式的解谜书，每章两关；右边是历史图文书，每章若干跨页，8 种内页组件、20 种交互样式。下面这本虚构的《灰港编年史》就是图文书的全量示例，所有截图都来自真实构建产物。

两种书型

先问类型，再生成

同一条 new_book.py 命令，用 --type 决定章节形态。两本书的工程结构完全一致，所以同一本书里也可以混用两种章节。

类型章节形态每章内容适合
puzzle
解谜书		 meta + Classic.tsx + spec.js + art.js 第一关：2 分钟的 React 小游戏
第二关：书页引擎，拾取 / 组合 / 特写翻页 / 两级提示		 小说、名著、悬疑故事改成的可玩电子书
history
历史图文书		 meta + pages: Page[]（纯数据） 6~12 个跨页，每页选一种组件：时间线、卡片、地图、家谱、对比、热点图、小测…… 历史、文明、人物、图鉴、编年史
命令。解谜书：new_book.py <目录> --type puzzle --title 书名 --cover leather --paper parchment； 图文书：new_book.py <目录> --type history --title 灰港编年史 --layout heraldic --emblem crown --cover wine --paper vellum。 地址栏加 ?cover=&paper=&layout=&emblem= 可临时预览封面。
1

封面：版式 × 徽章 × 配色

5 个实机样本

三种版式分别来自三个参考项目：classic 是《百年孤独》的烫金精装书，heraldic 是《玫瑰战争》斜放的纹章合拢书（点击会翻开），emblem 是《Vikings》那种书名在书外、书面只有烫金西文大字和徽章的手抄本。

徽章库

  • rose 都铎玫瑰（大图，移植自《玫瑰战争》）
  • longship 日轮长船（大图，移植自《Vikings》）
  • crown lily sun key feather seal boar compass candle：48×48 图形，外套勋章环

封面文字

  • kicker 顶部小字 · motto 标题下小字
  • latin 西文大字（emblem 版式按字数自动缩字号）
  • era 年代 · prompt 轻触提示
2

外壳：目录、跨页与翻页

桌面 + 手机

图文章不需要写布局：组件只声明「左页放什么、右页放什么」，PagedChapter 负责页眉、翻页栏、页码存档和手机端的上下堆叠。点选条目后，手机端会自动把详情滚进视野。

3

内页组件：8 种 × 20 种样式

全部来自示例书 ch1、ch2

每张卡片是一页真实的跨页：左图是实机截图，右下的代码是该页在 index.ts 里的实际写法（省略了部分文案）。字段完整表见 references/blocks.md。

CH.1 · 01

正文 · 首字下沉 text · dropcap

长文阅读的默认形态。左页放配图和引文，右页正文首字下沉。glossary 里的词在正文中变红，点按在右页顶部浮出释义。

kind: 'text', variant: 'dropcap',
title: '潮水之城',
image: 'illustrations/h-town.svg',
quote: { text: '城是海借给人的。', source: '—— 港务簿扉页' },
glossary: { '潮汐': '海水每日两涨两落……' },
text: ['灰港最早只是滩涂上几间晒盐的棚屋……', …]
CH.1 · 02

图文 · 热点 feature · hotspot

一幅要讲解的图（城景、器物、画作）。spots 的 x/y 是原图上的百分比，点编号后右页换成该处的注释。图按原比例显示，所以坐标永远准。

kind: 'feature', variant: 'hotspot',
image: 'illustrations/h-town.svg',
spots: [
  { x: 13, y: 40, title: '岬角灯塔', text: '1352 年建成，烧鲸油。' },
  { x: 50, y: 17, title: '圣灯大教堂', … },
]
CH.1 · 03

时间线 · 竖排 timeline · rail

年代顺序的首选。左页是带圆点的里程碑，右页展开详情，也可以用 ‹ › 逐条翻。kicker 写年份。

kind: 'timeline', variant: 'rail',
items: [
  { kicker: '1104', title: '盐棚', text: '…', image: '…' },
  { kicker: '1268', title: '城墙合拢', points: ['城门七座', '水门两座'] },
  { kicker: '1417', title: '大潮之年', quote: { text: '水到了教堂第三级台阶。' } },
]
CH.1 · 04

分类卡片 · 网格 cards · grid

一组同类事物（职业、兵种、食物、建筑）。cats 生成上方筛选标签，卡片用 icon + 标题 + 一句话；选中的卡片在右页展开详情。

kind: 'cards', variant: 'grid',
cats: [{ id: 'sea', label: '海上' }, { id: 'land', label: '岸上' }],
items: [
  { cat: 'sea', icon: '⚓', title: '船长', short: '按潮汐出海', text: '…' },
  { cat: 'pen', icon: 'feather', title: '港务书记', short: '写下一切' },
]
CH.1 · 05

分期对比 · 切换 compare · tabs

同一处地方在不同时期的样子。左页用蜡封按钮切换分期，图上还能再叠一层编号点；右页是当前分期的说明。

kind: 'compare', variant: 'tabs',
eras: [
  { icon: 'Ⅱ', kicker: '城墙期', title: '1250—1420',
    image: 'illustrations/h-town.svg',
    spots: [{ x: 13, y: 40, title: '灯塔', text: '1352 年点亮。' }] },
  { icon: 'Ⅲ', kicker: '远航期', points: ['防波堤两道'] },
]
CH.1 · 06

家谱 graph · tree

只写 parent，布局自动分层、父节点居中于子节点、直角连线。点人物看生平，右页底部列出亲属，可沿关系继续跳。

kind: 'graph', variant: 'tree',
nodes: [
  { id: 'a', title: '老奥斯', kicker: '1310—1371' },
  { id: 'b', parent: 'a', title: '马伦', kicker: '1338—1402' },
  { id: 'c', parent: 'a', title: '艾达', … },
],
groups: [{ id: 'keep', label: '守塔人' }, { id: 'kin', label: '亲族' }]
CH.1 · 07

地图 · 点位 map · pins

地点分布。kinds 生成图例筛选，x/y 是底图上的百分比。不写 image 时组件会画纸面经纬网和罗盘，没有地图素材也能用。

kind: 'map', variant: 'pins',
image: 'illustrations/h-map.svg',
kinds: [{ id: 'town', label: '城镇' }, { id: 'sea', label: '海上' }],
places: [
  { x: 44, y: 54, kind: 'town', icon: '★', title: '灰港', text: '…' },
  { x: 13, y: 44, kind: 'sea', title: '鸥岛' },
]
CH.1 · 08

小测 · 单选 quiz · choice

章末回顾。选错会抖动并解释为什么错，选对显示解析。最后一页的按钮是「读完本章」。

kind: 'quiz', variant: 'choice',
question: '灰港的城门按什么来开闭？',
options: [
  { text: '教堂的钟声', why: '钟声只在雾天报时。' },
  { text: '潮汐表', ok: true },
  { text: '日出日落', why: '港城跟着水，而不是太阳。' },
],
explain: '城门、市集、出海，全部按潮汐表安排。'
CH.2 · 01

正文 · 跨页排版 text · columns

长文跨左右两页连续排（前半在左页，后半在右页），左页首段仍下沉。适合没有配图的纯叙述页。

kind: 'text', variant: 'columns',
title: '出海之前',
text: ['十五世纪初，灰港的船还只敢沿着海岸走……', …],
glossary: { '星盘': '测量星体高度、推算纬度的铜制仪器。' }
CH.2 · 02

图文 · 左右分栏 feature · split

最朴素的图文对照：左图右文。图保持原比例，不再裁切，所以海图、长卷都能完整显示。

kind: 'feature', variant: 'split',
image: 'illustrations/h-map.svg',
caption: '灰港海湾图（示例）',
text: ['海图上不画国界，只画水深、礁石和避风处。', …]
CH.2 · 03

图文 · 上图下文 feature · stack

首段提到左页做成大字引文，右页上图下文。适合「先给一句气氛，再讲细节」的页面，避免左页空着。

kind: 'feature', variant: 'stack',
image: 'illustrations/h-town.svg',
text: [
  '天还没亮，水门就开了。渔船先走，商船随后……',   // 左页大字
  '退潮时码头空出一大片滩涂……',                    // 右页正文
]
CH.2 · 04

时间线 · 蜡封分组 timeline · seals

有时间段或王朝的阶段划分时用。左页是带年份的蜡封，点开才展开条目；用 ‹ › 翻到别的组，那一组会自动展开。

kind: 'timeline', variant: 'seals',
groups: [
  { id: 'v1', label: '第一次：绕岬', years: '1421' },
  { id: 'v2', label: '第二次：北岭', years: '1433' },
],
items: [
  { group: 'v1', kicker: '3月', title: '启航', text: '两条船，四十个人。' },
  { group: 'v1', kicker: '4月', title: '归港' },
]
CH.2 · 05

时间线 · 横轴 timeline · ribbon

每个节点都有图时用。左页显示当前节点的插图，右页是一条横向菱形年轴，适合「同一件东西的多次重建」这类叙事。

kind: 'timeline', variant: 'ribbon',
items: [
  { kicker: '1352', title: '木塔', image: 'illustrations/h-town.svg',
    caption: '最初的木塔', text: '烧鱼油，光只照得到鸥岛。' },
  { kicker: '1417', title: '被潮水冲毁' },
  { kicker: '1488', title: '镜灯', text: '加装铜镜，光能照到外海。' },
]
CH.2 · 06

分类卡片 · 手风琴 cards · accordion

要让读者一项项展开细读时用。右页每行一个条目，展开后正文直接接在下面；左页显示当前条目配图。

kind: 'cards', variant: 'accordion',
items: [
  { icon: 'compass', title: '星盘与罗盘', short: '导航',
    text: '星盘夜里用，罗盘雾里用。', image: '…' },
  { icon: '🧂', title: '盐', short: '货物，也是货币',
    points: ['腌鱼', '交易'] },
]
CH.2 · 07

分类卡片 · 翻面 cards · flip

冷知识、传闻、迷信这类轻内容。2 列卡片，点一下翻面看背面；左页只留标题、导语和「已翻开 n / N」的进度。

kind: 'cards', variant: 'flip',
items: [
  { icon: '🐈', title: '船猫', kicker: 'I',
    short: '船上必须有一只猫，否则老鼠会吃掉海图。' },
  { icon: '🔔', title: '不敲钟', kicker: 'II',
    short: '出港时不能敲钟，那是给死者的。' },
]
CH.2 · 08

对比 · 左右并排 compare · columns

只有两方（两种船、两个版本、两种制度）时最直观：左页 A，右页 B，不用来回切换。超过两项时两边都会出现切换标签。

kind: 'compare', variant: 'columns',
eras: [
  { kicker: '近海', title: '平底驳船', image: '…',
    text: '吃水浅，能在退潮的滩涂上搁浅等潮。',
    points: ['船员 6 人', '单桅'] },
  { kicker: '远洋', title: '三桅帆船', points: ['船员 40 人', '三桅'] },
]
CH.2 · 09

关系网 graph · web

不是血缘，而是结盟、敌对、联姻。links 的 dashed 用来表示冲突或间接关系；点人物后，与它相连的线会亮起。

kind: 'graph', variant: 'web',
nodes: [
  { id: 'salt', group: 'guild', x: 28, y: 26, title: '盐商行会' },
  { id: 'ship', group: 'guild', x: 72, y: 26, title: '造船行会' },
],
links: [
  { a: 'salt', b: 'ship', label: '争执', dashed: true },
  { a: 'salt', b: 'light', label: '联姻' },
]
CH.2 · 10

地图 · 路线 map · journey

places 的顺序就是路线。左页把走到当前站的路径连成虚线，右页配「第 n / N 站」，可以当航行日志逐站推进。

kind: 'map', variant: 'journey',
places: [
  { x: 44, y: 54, kicker: '第 1 天', title: '灰港启航' },
  { x: 13, y: 44, kicker: '第 3 天', title: '鸥岛', text: '补充淡水。' },
  { x: 10, y: 15, kicker: '第 8 天', title: '灰海' },
  { x: 44, y: 54, kicker: '第 19 天', title: '归港' },
]
CH.2 · 11

小测 · 排序 quiz · order

把事件按时间排好。options 按正确顺序书写，显示时打乱；点错会清空已选并抖动，逼你重来。

kind: 'quiz', variant: 'order',
question: '把灯塔的历史按时间先后排好。',
options: [              // 按正确顺序写，显示时打乱
  { text: '木塔点亮' },
  { text: '加石砌底座' },
  { text: '被大潮冲毁' },
  { text: '全城捐石重建' },
  { text: '装上铜镜' },
]
CH.2 · 12

正文 · 单栏尾声 text · plain

不配图、不下沉：左页一句居中引文，右页短正文。用来收尾，让读者在合上书之前停一下。

kind: 'text', variant: 'plain',
title: '尾声',
quote: { text: '灯塔守护近处，星星守护远处。' },
text: ['林恩的船再也没有回来……', '但从那以后，灰港的每一条船出港时……']

怎么复用

三条命令开始

生成

S=interactive-book-builder
python3 $S/scripts/themes.py list
python3 $S/scripts/new_book.py 书名目录 \
  --type history --title 灰港编年史 \
  --layout heraldic --emblem crown \
  --cover wine --paper vellum --install

加章 / 换主题

python3 $S/scripts/add_chapter.py 书目录 3 --kind paged
python3 $S/scripts/themes.py set 书目录 --cover umber --paper linen

记住三件事

  • 图文章只写数据，不写组件：复制示例里同 kind·variant 的页面改内容。
  • 颜色只用 ink / accent / paper / tint(k)，换纸张主题后仍然协调。
  • SVG 当底图时记得写 width/height，否则没有固有尺寸、显示不出来。
