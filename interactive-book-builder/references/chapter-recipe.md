# 章节配方

一章 = `src/chapters/chN/` 文件夹，外加 `public/illustrations/chN.svg`。用 `add_chapter.py` 复制 ch1 后逐个文件重写即可。

## 1. 从原著到一章

1. 从这一章的原文里挑出 **一个核心意象**（例如蜡烛、雨、名字、鱼、黄蝴蝶），两关都围绕它展开。
2. **第一关（Classic）= 读**：轻量的 React 小游戏，让玩家"进入这段文字"。要求 30 秒内能看懂规则，1~3 分钟能通过。
3. **第二关（spec）= 做**：锈湖式的场景解谜，把原著情节变成一条因果链，最后用 `g.finish()` 结束。时长 5~10 分钟。
4. **摘录（meta.excerpt）**：通关后收集的原著金句，会出现在过场页和摘录册里。

## 2. 第二关谜题链设计

- 链长 5~8 步，最好有 1~2 处可以并行推进（例如同时找两样东西），避免完全线性。
- 每一步写成：`动作 → S.flag → 画面变化（data-if / data-cls）→ 旁白`。先把整条链写进 spec.js 顶部注释再动手。
- 推荐的谜题类型（引擎都已支持）：
  - **拾取 + 组合**：两件物品合成第三件（`recipes`）。
  - **对物使用**：选中物品后点击场景（`use`）。
  - **特写翻页**：在主场景点击某处后打开特写（`scenes` + `g.open`），在特写里拿东西或解局部谜题。
  - **密码/转轮**：数字或符号循环切换（参考 ch1 的 `dial0-2` 和 `bk-roll`）。线索放在别的场景或信件里。
  - **文字页**：读信、给物件命名、拼字（`sheets` + `bk-tiles`），用 `data-act` 提交。
  - **状态切换**：点灯、开窗、拉帘，切换后场景出现新东西（`data-if`）。
  - **计时/节律**：用 `g.every` 驱动的动态元素（谨慎使用，必须能自动通关）。
- 线索要**在画面中看得见**：数字直接画进场景（例如星星的分组），而不是只写在旁白里。
- 每个热区都要有回应：没用的东西也给一句有文学味的旁白（用 `lines` + `g.cycle` 轮流说）。
- 失败时的旁白要给方向，例如"火苗在指尖晃了晃，它该去点亮什么"，不要只说"不行"。
- `hint` 要按链条顺序覆盖**每一步**；soft 是方向，hard 是具体到点哪里的做法。
- `solve` 必须把所有 flag 设成通关前一刻，包括 `xxxTaken` 和清空 `inv`。

## 3. 第一关（Classic.tsx）常见玩法

参数：`{ onComplete, lang, triggerAutoSolve }`。完成时 `setTimeout(onComplete, ~1500)` 并用 ref 防止重复触发；`triggerAutoSolve` 变为真时直接展示完成态并调用 finish。

| 玩法 | 做法 |
|---|---|
| 句子拼回（ch1 示例） | 原文切成 4~7 段并打乱，按顺序点击，点错就清空重来 |
| 填空/选词 | 原文挖掉 3 个关键词，从 6 个候选中选 |
| 连线/配对 | 人物 ↔ 物件 / 名字 ↔ 特征，点两端完成配对 |
| 记忆翻牌 | 4×3 张牌，配对成功时显示原文短句 |
| 排序/时间线 | 拖拽或点击，把事件按顺序排好 |
| 找不同/找物 | 在一幅 SVG 里找出 N 个隐藏物件 |
| 擦拭显影 | 点击或拖动擦去雾气、尘土，露出下面的文字 |

样式要求：颜色只用 Tailwind 的 `ink / accent / paper / paper2 / foil`（跟随主题），字体用 `font-serif` / `font-display`。可以复用 `stained-parchment`、`btn-ink`、`fade-in`、`bk-shake`。不要写死颜色，否则切换主题后会出问题。

## 4. 美术约定（art.js）

- 导出 `ART = { main(S?), <特写名>(S?), ICONS: {id: svg}, ... }`，在 spec 里用 `svg: S => ART.xxx(S)` 引用。
- 主场景结构：`<svg class="bk-scene" viewBox="0 0 800 800">` → `<g filter="url(#bk-wob)">` 背景（墙、地、大型家具）→ 状态物件（`data-if`）→ **热区放最后**。
- 描边用 `INK`，填色从 `PAL` 里取；一个画面中红色（`PAL.red`）只用 1~2 处，用来引导视线到关键物件。
- 大面积色块上叠一层排线（`url(#bk-h)`，opacity 0.3~0.6），营造版画质感。
- 元素 id、自定义 class、自定义 defs 一律加 `chN-` 前缀（add_chapter 会自动把 `ch1-` 替换成 `chN-`）。
- 图标的 viewBox 为 60×60，线条要粗（stroke-width ≥ 2），保证缩小后仍能看清。
- 左页插图 `public/illustrations/chN.svg`：竖版 4:3 左右，画这一章的核心意象即可，可以用柔和的渐变和光晕。

## 5. meta（index.ts）写法

```ts
meta: {
  id: 3,                                   // 连续编号 = 目录顺序
  title: { zh: '雨', en: 'The Rain' },     // 只做中文时可以直接写字符串
  subtitle: 'Cuatro años de lluvia',       // 目录小字，用西文/拉丁文更有书卷气
  description: '...左页导读，2~3 句...',
  stage1: '...第一关怎么玩（也是第一关 ✧ 的提示）...',
  stage2: '...第二关怎么玩（通用操作说明）...',
  excerpt: { text: '“原著金句”', source: '—— 《书名》第三章' },
  image: 'illustrations/ch3.svg',
}
```
